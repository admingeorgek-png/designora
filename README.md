# Designora

A Canva-inspired design platform starter with its own branding and UI.

## Run locally
cd backend
npm install
npm start

Then open http://localhost:3000

## Current MVP
- Landing page
- Dashboard
- Design formats
- Canva-style editor layout
- Text controls
- Color controls
- Basic element creation
- Backend health endpoint

Next steps: real drag/resize/rotate, image uploads, layers, templates, persistence, authentication and PNG/PDF export.
